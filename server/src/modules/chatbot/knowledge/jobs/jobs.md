# ZOBHUNGER Jobs

The Jobs page lets visitors search roles by keyword, location, category and job type, then read responsibilities before applying.

## Public job categories

- Sales
- Promoter
- Field Work
- Marketing
- Telecalling
- Recruitment
- Operations

## Job types represented by the public catalogue

- Full-time
- Contract
- Project-based
- Part-time
- Gig

## Location catalogue

The current demonstration catalogue contains: Bengaluru, Delhi, Lucknow, Mumbai, Prayagraj, Pune. In production, job listings are backed by the configured API, so actual published locations and vacancies can change.

## Demo versus live jobs

When the site is running in mock/demo data mode, the Jobs page explicitly labels roles as **fictional examples** and says they are not live vacancies. The chatbot must preserve that distinction and must not present demo roles as current job openings.

For a worker who wants to be considered generally, the public profile flow at `/careers/apply` is the appropriate starting point.
