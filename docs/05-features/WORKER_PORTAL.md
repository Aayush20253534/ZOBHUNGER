# Worker Portal

## Access lifecycle

Workers use dedicated registration/verification/login/recovery routes. The broader intake process can begin from the public careers/profile flow before portal access is approved.

## Profile and resume

Workers can read/update their profile and upload/remove a private PDF resume. Resume handlers enforce size/type rules and private storage behavior.

## Jobs

Workers can:

- browse paginated/filterable opportunities;
- view job details;
- save/unsave jobs;
- apply through worker application flows;
- review existing applications and eligible withdrawal actions.

## Assignments and attendance

Confirmed workforce assignments appear in the portal. Workers can inspect assignment/day/month attendance views and submit the supported attendance action/request for an assignment.

## Earnings

Approved earnings statements and details become visible to the worker, including CSV export for a statement. Draft creation, adjustments, approval and payment recording are admin functions.

## Privacy boundary

A worker may only access data linked to the authenticated worker identity. Private worker data is not part of public Redis/site caching.
