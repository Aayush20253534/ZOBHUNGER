# Partners, Vendors, Careers and Internships

## Partner applications

Businesses/agencies can submit partner applications through the public partner flow. Admin operations review applications and manage partner access lifecycle separately from ordinary business self-service.

## Vendor empanelment

The vendor flow captures organizations offering workforce, recruitment, advertising/marketing, business/operational or specialist services. Applications and private vendor documents are reviewed through admin vendor screens; approved/managed vendor records can appear in the directory view.

## Careers

The careers flow captures candidate/worker-profile information and resume material for review. Admin career workflows can review applicants and connect approved people into worker/hiring operations where appropriate.

## Internships

Public internship applications have their own review domain. Internship document-payment checkout is a separate payment capability; an internship application does not become “paid” merely because a browser returned from a payment page.

## Shared intake

These flows can feed the operational intake system so teams can assign cases, add internal notes and track workflow status while preserving the original source record.
